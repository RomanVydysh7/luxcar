# LuxCar — Premium Car Auction

## Назва
**LuxCar** — веб-платформа для онлайн-аукціону преміальних автомобілів з реєстрацією користувачів, ставками, каталогом лотів та адміністративною панеллю.

## URL
**Local Frontend URL:** [http://127.0.0.1:5173](http://127.0.0.1:5173)

**Local API URL:** [http://127.0.0.1:4000](http://127.0.0.1:4000)

---

## Стек технологій
- **Frontend:** React.js, Vite, React Router, CSS3 з ефектом Glassmorphism
- **Backend:** Node.js, Express.js
- **База даних:** SQLite (`data/luxcar.sqlite`)
- **Авторизація:** JWT token + bcryptjs для хешування паролів

---

## Функції
Система забезпечує основний цикл роботи автомобільного аукціону:
- **Каталог автомобілів:** Перегляд активних лотів, пошук за ключовим словом, фільтрація за маркою автомобіля.
- **Деталі лота:** Окрема сторінка автомобіля з фото, описом, характеристиками, поточною ціною та історією ставок.
- **Реєстрація та авторизація:** Користувач може створити акаунт, увійти в систему та зберігати сесію через JWT.
- **Ставки:** Авторизований користувач може зробити ставку, яка має бути більшою за поточну ціну лота.
- **Додавання авто:** Авторизований користувач може створити новий автомобільний лот для аукціону.
- **Адмін-панель:** Адміністратор бачить статистику, список користувачів, список лотів та може змінювати статус лота.
- **Рольова система:** Дві ролі — `user` та `admin` з різними рівнями доступу.
- **Seed-дані:** При першому запуску створюється адміністратор і стартові автомобільні лоти.

## Авторизація

### Ролі та доступ:

1. **Admin (Адміністратор):** Повний доступ до адмін-панелі, статистики, користувачів та керування статусами лотів.
   - **Email:** `admin@luxcar.ua`
   - **Пароль:** `admin123`

2. **User (Користувач):** Може переглядати каталог, реєструватися, входити в акаунт, створювати лоти та робити ставки.
   - **Email:** можна зареєструвати свій
   - **Пароль:** мінімум 6 символів
   - *Примітка:* Нові акаунти реєструються самостійно на сторінці `/register`. Роль `user` призначається автоматично.

## Node.js API (Backend)

Всі ендпоінти знаходяться в Express-сервері `server/index.js`.
SQLite ініціалізується у файлі `server/db.js`.

| Endpoint | Методи | Доступ | Опис |
|---|---|---|---|
| `/api/health` | GET | Public | Перевірка роботи API |
| `/api/auth/register` | POST | Public | Реєстрація нового користувача |
| `/api/auth/login` | POST | Public | Авторизація користувача та отримання JWT |
| `/api/auth/me` | GET | Auth | Отримання даних поточного користувача |
| `/api/lots` | GET | Public | Список лотів, пошук і фільтрація |
| `/api/lots/:id` | GET | Public | Деталі конкретного лота та історія ставок |
| `/api/lots` | POST | Auth | Створення нового автомобільного лота |
| `/api/lots/:id/bids` | POST | Auth | Створення ставки для лота |
| `/api/admin/stats` | GET | Admin | Статистика системи |
| `/api/admin/users` | GET | Admin | Список користувачів |
| `/api/admin/lots` | GET | Admin | Список усіх лотів |
| `/api/admin/lots/:id/status` | PATCH | Admin | Зміна статусу лота |

## Сторінки проєкту

### 1. Головна сторінка / Каталог
- **URL:** `/`
- **Опис:** Публічна сторінка з hero-блоком LuxCar, пошуком, фільтром за маркою та списком активних автомобільних лотів.

### 2. Деталі лота
- **URL:** `/lots/:id`
- **Опис:** Детальна сторінка автомобіля: фото, назва, марка, модель, рік, пробіг, паливо, коробка передач, місто, опис, поточна ціна та історія ставок.

### 3. Авторизація
- **URL:** `/login`
- **Опис:** Форма входу за email та паролем. Для тестування доступний адміністратор `admin@luxcar.ua / admin123`.

### 4. Реєстрація
- **URL:** `/register`
- **Опис:** Форма створення нового користувача. Після реєстрації користувач автоматично входить у систему.

### 5. Додавання автомобіля
- **URL:** `/sell`
- **Опис:** Сторінка для авторизованих користувачів. Дозволяє створити новий лот з назвою, маркою, моделлю, роком, пробігом, містом, фото, описом і стартовою ціною.

### 6. Адмін-панель
- **URL:** `/admin`
- **Опис:** Сторінка тільки для адміністратора. Містить статистику системи, список лотів зі зміною статусу (`active`, `sold`, `paused`) та список користувачів.

## Запуск проєкту

### 1. Встановити залежності
```bash
npm install
```

### 2. Запустити frontend і backend
```bash
npm run dev
```

Після запуску:
- Frontend: [http://127.0.0.1:5173](http://127.0.0.1:5173)
- Backend API: [http://127.0.0.1:4000](http://127.0.0.1:4000)

### 3. Зібрати production build
```bash
npm run build
```

### 4. Запустити тільки backend
```bash
npm start
```

---

## Примітки
- SQLite база створюється автоматично при першому запуску backend.
- Стартові лоти та admin-користувач додаються автоматично через seed-логіку.
- Для коректної роботи frontend використовує proxy `/api` на `http://127.0.0.1:4000`.
- Файл бази даних не потрібно створювати вручну.
